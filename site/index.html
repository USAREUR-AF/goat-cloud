goat-cloud

Every cloud resource has an owner, a purpose and a lifetime that anyone can look up.

Developers deploy from their own repositories with no central gate and no ticket. Each night a scan finds what has no owner or has outlived its stated expiry; its owner is warned, and it is removed.

What it is

Four small parts. Three properties.

A contract of tags that each repository applies in its own code. A registry in which each repository records where its infrastructure state lives. A nightly scan that compares what exists with what the repositories claim. Removal that runs only behind a warning, an approval and a deliberate switch.

Engineered

Ownership is written in code

Every repository states, in its own infrastructure code, what it owns and for how long. Nothing is entered in a console or a spreadsheet, and no central team edits a list when a repository joins.

Observable

Anyone can look it up

The scanner reads infrastructure state where it already lives and compares it with the account. Nothing is installed on a host and no deployment pipeline changes.

Regulated

Removal, behind gates

A resource that is unowned or expired does not stay because nobody got to it. Its owner is told, a period passes, and it goes. Removal is the part with the most safeguards.

Status

AWS is built and runs each night. Azure and Google Cloud scan; the rest is designed.

Built means the code is complete and usable today. Written means the document or code exists. Designed means the approach is decided and no code exists. On AWS the contract attaches to each resource; on Azure to the resource group; on Google Cloud to the project.

What you see

Each finding names a resource, an owner and a cost.

Two checks decide what the scan reports

A resource is owned when a registered repository's state contains it. The scanner reads the state each registry entry points to; it never asks a deployment tool what it manages.

From the concepts document. A diagram, not a capture. The figure scrolls sideways.

Findings

One finding is one problem with one resource, in one of four categories: tags, unclaimed resources, lifecycle and schedule. Each carries the resource, its state, its tags, its age, its estimated monthly cost and a recommendation.

A real capture, synthetic data.

Repositories

A repository joins by writing its own registry entry: its URL, its tool, where its state lives. No central list is edited. The view shows each repository's resources, findings and compliance rate.

A real capture, synthetic data: seven repositories using Terraform, the Serverless Framework, Pulumi and CDK.

Cost

A monthly estimate per resource, the total cost of everything with a finding, billed spend per service, and budget alerts at 50, 80, 100 and 120 percent of a limit.

A real capture, synthetic data.

Deletion is off until an administrator turns it on

The function that warns owners has no delete permission. The executor is a second function with its own role, and it exists only while it is armed. Dry run is the default. Protected types, protected environments, a Protected tag and a protected list each stop a deletion.

Try it

The demo needs no account. A first report from AWS takes one Terraform root.

On your machine

The demo generates an invented estate and serves the dashboard against it. It needs Python 3.11 or newer and boto3, which the dashboard code imports.

$ python3 demo/generate.py
152 resources, 29 findings {'HIGH': 16, 'MEDIUM': 9, 'LOW': 2, 'INFO': 2} -> demo/data

Real output. Two of the 29 are notices of an expiry within 14 days, which the dashboard leaves out of its count of 27. The output scrolls sideways.

In your AWS account

The quick start creates one Terraform root that tags its own resources, registers itself and deploys the scanner, runs one scan and downloads the report. It deletes nothing. The quick start allows about 20 minutes and states a cost under 1 USD a month at that size.

module "compliance" {
  source = "git::https://github.com/USAREUR-AF/goat-cloud.git//modules/aws/compliance-tags?ref=v0.1.0"

  project         = "acme"
  environment     = "dev"
  repository_url  = "https://github.com/acme/example-repo"
  lifecycle_value = "persistent"
}

Scope

One question: whose is this, and should it exist?

goat-cloud governs what shares one account, subscription or project. It has one contract and no rule language. It detects after creation; it does not refuse an untagged resource at creation, detect cost anomalies, optimize rates, or compare a claimed resource with its definition. The README names the tool to use for each of those.
